[[-Database Fundamentals start tab]]
	Covers the fundamental ideas behind databases. Why we use them, what for, and the general structure of one.

[[-Relation Model and Algebra (for DB systems) start tab]]
	Covers the relational model (of a database), along with methods to theoretically interact with one (relational query language or relation algebra). SQL follows the relation model, so this helps with understanding SQL operations.

[[-Using SQl (for DB systems) start tab]]
	Covers the use of SQL for creating DB, fetching data, and modifying data. Both basic operations and more advanced ones. Also covers utilizing SQL queries in other languages (specifically java).

[[-Database Design and the E-R Model start tab]]
	Covers how a database is usually designed, including the Entity-Relationship Model which is commonly used in the initial design of a database.
