
(bowtie symbol)

operates on two relations whose values are same on all attributes that are common to both relations

if one DB has table with attributes A B C D, and another table of B C E

the natural join is the table with the attributes A B C D E

the natural join of two tables sharing no attributes is a cartesian product 
	(most of the time but in some cases it will also generate an error)
