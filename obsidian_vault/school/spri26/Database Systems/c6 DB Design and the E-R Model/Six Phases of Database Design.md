
1) Conduct an Initial Study:
	- Characterize the user's data needs,
		- Who is the user and how will they interact with the DB?
	- Determine the projects scope and any constraints.

2) Choose a Database Model for the Final DB:
	- File Model
	- Relational Model (csci330 teaches the Relational Model)
	- Entity-Relationship Model
	- Object-based Data Model
	- etc

3) Develop a Conceptual Schema:
	- A blueprint for the DB to capture the users' data needs.
	- (csci330 teaches using the E-R Model for this step)

4)  Review the Schema:
	- Ensure it supports all functional requirements.
	- All data required for all outputs present in conceptual schema.

5) Map Conceptual Schema to a Logical Schema:
	- Convert the conceptual schema DB into the blueprint for the DBMS being used.
	- (in csci330)
		- Convert E-R diagram into Relation Model tables and constants

6) Map Logical Schema to Physical Schema:
	- Create the physical DBMS on the physical disk storage
		- Files, directories, indexes, etc
	- Based on the Logical Schema already derived.
