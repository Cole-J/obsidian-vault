General Components
- Divided Rectangles: Entity Sets
	- Top part is the name of the Entity Set
	- Bottom part is the Attributes (Rows) with Primary Keys underlined
	- [[Representing Composite Attributes in an E-R Model Diagram]]
	- [[Representing Multi-valued Attributes in an E-R Model Diagram]]
	- [[Representing Derived Attributes in an E-R Model Diagram]]
- Diamonds: Relationship Sets
- Solid Lines: Link of a Entity Set to a Relationship Set
	- [[Mapping Cardinality in an E-R Model Diagram]]
- Dashed Lines: Link of a descriptive attribute to a Relationship Set
- Undivided Rectangles: Descriptive Attribute of a Relationship Set
