
inheritance allows you to define a very general class and then later define more specialized classes based off the general class

this creates a hierarchy of base or super classes and derived or sub classes

the primary keyword for this is 'extends'

or 'public class subclass extends superclass'

'super' is also a keyword which refers the 'superclass'

'super' can be used as a constructor or reference just like 'this' is in a class



the subclass declares more or changes preexisting variables and methods from the superclass
[[overriding in java]]



you can also use the 'final' keyword to stop any subclasses from modifying the value or method



remember that a subclass will not inherit private variables from the subclass, as so it must use the superclass methods to access or modify the private variable
