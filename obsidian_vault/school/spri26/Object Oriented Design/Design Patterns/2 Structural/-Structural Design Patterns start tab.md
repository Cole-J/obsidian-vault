
The [[Design Pattern 5 Adapter|Adapter Pattern]] is used to define a way to adapt one interface, to some incompatible implementation or object. Allowing calls to the interface to be rerouted to the incompatible.

The [[Design Pattern 6 Proxy|Proxy Pattern]] is used to define a way to create a proxy object between two other objects. Allowing for specific checks or logic to happen within a proxy object before having the proxy conduct further calls to the lower object.
