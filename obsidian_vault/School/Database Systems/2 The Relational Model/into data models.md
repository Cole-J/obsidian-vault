data models
	the underlying structure of a DB
	has a collection of tools for describing
		data
		data relationships
		data semantics
		integrity constraints
	classification of data models
		older models (before 1970 and 1980)
			ex:
				network model
				hierarchical model
			model tied closely to underlying implementation
				causes an issue if implementation needs to be changed
		new models (1980+)
			relational model
			entity relationship model
			object based data model
			semi structured data models
