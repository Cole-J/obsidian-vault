Two tier and three tier architecture

first () is client, second () is server

two tier
	(user -> application) -> (database system)
three tier
	(user -> application client) -> (application server -> database system)

for a web application which is better?
	in the two tier, on a web application, the users client is accessing the database directly
	in a three tier, DB is abstracted away from the client

Three tier is more secure but also takes longer
