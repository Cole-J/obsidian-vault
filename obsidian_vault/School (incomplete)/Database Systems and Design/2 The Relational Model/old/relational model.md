Relational model
	collection of tables to represent both data and relationship.
	-
	tables have unique names and fixed set of columns.
		Tables are also known as relations because each row represents a relationship among a set of values
		A relation (table) is a set of rows (tuples).
		A row (tuple) is a list of values
	-
	think spreadsheet.

Remember that (syntax)
	Relation <=> Table
	Tuple <=> Row
	Attribute <=> column
