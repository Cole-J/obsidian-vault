
| Feature             | Description                                                                       | Example Syntax                     |
| ------------------- | --------------------------------------------------------------------------------- | ---------------------------------- |
| **Package**         | Organizes code and prevents naming collisions. Maps directly to file directories. | `package com.mycompany.utils;`     |
| **Specific Import** | Links exactly one single class to the current file.                               | `import java.util.Scanner;`        |
| **Wildcard Import** | Exposes all classes within a single package layer.                                | `import java.util.*;`              |
| **Static Import**   | Grants direct access to static fields/methods without class qualifiers.           | `import static java.lang.Math.PI;` |
