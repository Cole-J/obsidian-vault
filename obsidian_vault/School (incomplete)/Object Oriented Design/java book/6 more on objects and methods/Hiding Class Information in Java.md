
When defining behaviors (variables) methods (functions) or classes in java you must also give them one of the following access modifiers:

1. public +:
	- Visible to all objects within or interacting with the class.
2. private -
	- Only visible to other behaviors or methods within the same class.
3. protected \#
	- Only visible to objects within the same class hierarchy or package.
4. default ~
	- Only visible to objects inside the same package.

The symbol next to the attribute name is what's used to identify the visibility in a [[-uml class diagram start tab|UML Diagram]] (+, -, \#, or ~).
